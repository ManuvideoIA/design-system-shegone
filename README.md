# Shegöne — Design System

Repository del design system del brand Shegöne: identità visiva, palette, tipografia, tono di voce e copy bank.

## Contenuto

- **`design-system.html`** — documento completo e navigabile (apri il file nel browser). Contiene: concept del brand, logo e varianti, palette colori, tipografia, direzione visiva/fotografica, tono di voce, copy bank.
- **`CLAUDE.md`** — versione compatta del design system in formato istruzioni, pensata per essere incollata nelle istruzioni personalizzate di un progetto Claude (claude.ai) o letta automaticamente da Claude Code, così ogni contenuto generato è già coerente col brand.
- **`assets/logo/`** — asset vettoriali e raster del logo:
  - `logo-completo.svg` — lockup integrale (cerotti + wordmark), a colori, sfondo trasparente
  - `wordmark.svg` — solo wordmark, vettoriale, ricolorabile
  - `wordmark-chiaro.png`, `wordmark-nero.png`, `wordmark-grigio.png` — wordmark isolato nelle 3 varianti colore, sfondo trasparente

## Brand in breve

Streetwear, target 20–35 anni. Concept: kintsugi — la crepa non si nasconde, si mostra. Tre parole guida: **chiaro, sintetico, freddo**.
Colore primario: `#497A84`. Font: Space Grotesk (display) + Inter (corpo testo).
